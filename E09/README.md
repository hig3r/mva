# E09_03 階層的クラスタリング（Ward法）
- 提出 Moodle
- 期限 2026-12-02水13:30
- *大注意* `.ipynb`の提出でなく`.csv`と`png`の提出です．最適なクラスタ数Kをテキスト入力欄に書いてください．

E09_02 と同じ個人別データを，
[E09_03_ward.ipynb](./mva_2026_E09_03_ward.ipynb)を参考にしてクラスタリングしよう．デンドログラムの画像を`.png` ファイルに保存して提出しよう，K=2,3,4,5,6のうち，CH基準を用いて最適なクラスタ数Kを決定し，その結果を`.csv`ファイルに保存して提出しよう．最適なクラスタ数Kは，テキスト入力欄に書くこと．

教師なし学習であるため，`model.fit()`にラベルなしのデータ`X`のみを渡している（分類タスクと異なり，目的変数`y`を渡していない）ことに注意しよう．

階層的クラスタリングであるため，訓練データと別のデータ点が与えられると，そのデータ点がどのクラスタに属するかを判定することはできないことに注意しよう（最初からクラスタリングやり直しになる？）．そのため，`.predict(X_test)`のようなメソッドは存在しない．代わりに，model に保存された，訓練データに付されたラベル `.label_`を読み出す（または `.fit_predict(X)`を用いて，訓練データ`X`に対して両方を一度に実行する）．

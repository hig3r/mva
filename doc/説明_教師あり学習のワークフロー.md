# 機械学習の流れ
```mermaid  
flowchart TB
    subgraph workflow[" "]
        direction LR

        subgraph training
            direction TB
            X1([X_train])
            Y1([y_train])
            M1["Y = 3 + 2x + ε<br/>R² = 0.98"]
            X1 -->|.fit()| M1
            Y1 --> M1
        end

        subgraph prediction
            direction TB
            X2([X_train])
            X3([X_train])
            X4([X_test])

            M2["Y = 3 + 2X + ε<br/>R² = 0.98"]

            P1([y])
            P2([y])
            P3([y])

            T2([y_train])
            T3([y_test])

            X2 --> M2
            X2 -.-> P1
            X3 -.-> P2
            X4 -.->|.predict()| P3

            P2 <--> T2
            P3 <--> T3
        end
    end

    M0["Y = a + bx + ε"]
    M0 ~~~ M1
    M1 ~~~ M2

    style workflow fill:none,stroke:none
    style training fill:none,stroke:none
    style prediction fill:none,stroke:none
    style M0 fill:white,stroke:black,stroke-width:2px
    style M1 fill:white,stroke:black,stroke-width:2px
    style M2 fill:white,stroke:black,stroke-width:2px
    ```

# Pythonの関数の呼び方

ここでは，関数の定義方法には触れずに，関数の呼び出し方，特に引数の書き方について説明します．

Pythonでは，関数名の後に括弧 `()` をつけ，引数を渡して関数を呼び出します．

```python
def square(x):
    return x**2

print(square(5))  # 出力: 25
```

## 関数の仕様

関数の引数 parameters や返り値をすべて記憶するのは不可能です．Pythonのライブラリでは，公式ドキュメントが整備されているので，それを調べましょう．AI chatにきいたり，解説記事を読んだりするのも役立ちますが，最終的には本家の公式ドキュメントを確認しましょう．


## 関数，メソッドの実行結果
実行結果は，返り値として返されたり，オブジェクトのプロパティ（構造体のメンバーのことです）として格納されたりします．後者の場合，そのプロパティを読み出したり，別のメソッドに渡したりすることで，実行結果を利用できます．

## 固定の引数

関数が受け取る引数の数が決まっている場合は，その数に合うように引数を渡します．引数をカンマ `,` で区切って並べると，左から順番に対応づけられます．

```python
def power(base, exponent):
    return base**exponent

print(power(2, 3))  # base に 2，exponent に 3 が渡される
```

この関数の呼び出しでは，引数を2つ渡す必要があります．必要な数より少なくても多くても，エラーになります．

## 任意個数の引数

関数によっては，引数をいくつでも受け取れます．たとえば `print` は，複数の値をカンマで区切って渡せます．

```python
print("赤", "青", "緑")
```

C言語でも`printf`はこのタイプでしたね．


## キーワード引数

引数名と値を `名前=値` の形で指定する方法を，キーワード引数といいます．引数の順番が分かりにくい場合や，一部の引数だけを指定したい場合に便利です．

```python
print("赤", "青", end="！\n", sep=" と ")
```
この例では，`sep` が値の間に入れる文字列，`end` が最後に出力する文字列を指定しています．キーワード引数は，関数が用意している引数名を使って指定し，順番は問いません．位置で渡す引数とキーワード引数を一緒に使うときは，位置で渡す引数を先に書きます．

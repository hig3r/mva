# 訓練データと検証・テストデータへの分割

  データ$(X,y)$ から $\hat{\beta}$ を推定したとき，
  今回のデータの細かい特徴を捉えてしまったのか，
  モデルの一般的な特徴を捉えたのかわからない．

  図では，データすべてを使うとそれなりになめらかな補間（赤い線）が得られるが，モデルから追加データが来た時に，それらのデータもうまく説明できるのかはわからない．

  そこで，手元にあるデータの一部（青い点）を訓練データ(training data)として使って補間（青い線）を行い，残りのデータを検証・テストデータ(validation/test data)として性能評価（決定係数を求めるのとか）することがある．

scikit-learn では，`train_test_split` という関数で分割できる．
```python
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
```

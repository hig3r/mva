# オブジェクトのメンバーを表すピリオド

C言語を通過した人は，構造体のメンバーにアクセスする時に，`.`を使うことを知っていると思います．
```C
struct Point {
    int x;
    int y;
};
struct Point p;
p.x = 1;
p.y = 2;
printf("%d %d\n", p.x, p.y);
```

Python では，（構造体を一般化した）クラスの，（インスタンス, オブジェクト）メンバーにアクセスする時に，`.`を使います．メンバーは，変数（データ）ばかりでなく，関数（メソッド）であることもあります．関数は`()`があることで区別されます
```python
z = complex(3, 4)   # 複素数 3 + 4i

# データメンバー（呼び出し括弧 () なし）
print(z.real)        # 3.0  ← 実部というデータ
print(z.imag)         # 4.0  ← 虚部というデータ

# メソッド（呼び出し括弧 () あり）
print(z.conjugate())  # (3-4j)  ← 共役複素数を計算する関数
print(cojugate(z))      # と書くこともできますが，z.conjugate() の方が自然です
```
この用法は，ライブラリの階層化をたどる`.`とはとりあえず別です．

### Chain of Member Access
メンバーの中にメンバーがある場合，`.`を連続して使うことができます．これを「メンバーアクセスの連鎖」と呼びます.
`z.conjugate()` は，それ自身複素数である（`conjugate(z)`の返り値が複素数である）ため，そのメンバーにアクセスできます．

```python
z.conjugate().real  # 3.0
z.conjugate().conjugate() # (3+4i)
z.conjugate().conjugate().imag  # +4.0
((z.conjugate()).conjugate()).imag # 同じだが不自然な書き方
```
